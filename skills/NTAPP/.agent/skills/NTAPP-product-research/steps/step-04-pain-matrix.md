## 🛑 MANDATORY EXECUTION RULES (READ FIRST):
- CẤM dùng các nỗi đau sáo rỗng (như "Khó sử dụng"). Phải tìm ra "Duct-tape solutions" (Cách họ chắp vá).
- Ghi ngay kết quả vào file đích.

## Nhiệm vụ:
1. BẮT BUỘC dùng Web Search để tìm đọc các phàn nàn (complaints), review 1 sao, thảo luận trên Reddit/Forum về các sản phẩm đối thủ.
2. Tổng hợp các rào cản, nỗi bực dọc, và các Workaround (cách làm thủ công) mà Persona đang phải chịu đựng.
3. BẮT BUỘC vẽ BẢNG MARKDOWN Ma Trận Nỗi Đau với các cột:
   - `[Phân khúc]` (Persona)
   - `[Nỗi đau]` (Pain Point)
   - `[Mức độ nghiêm trọng]` (Severity: High/Medium/Low dựa trên data)
   - `[Workaround hiện tại]` (Cách khách hàng đang tự giải quyết)
4. Ghi toàn bộ nội dung + Bảng vào file `{raw_pain_matrix}`.
