# Bắt đầu nhanh

Cài đặt môi trường VDS và chạy lệnh đầu tiên trong vòng 5 phút.

## Yêu cầu

- Python 3.14+, uv, Git, Docker

## Cài đặt

```bash
cd vds-scripts
git pull --ff-only origin HEAD
uv sync
vds-cli --help
```
