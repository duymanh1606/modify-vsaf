# Điều Phối Viên BRD

> Tạo và xác thực tài liệu yêu cầu kinh doanh.

## Phạm vi

- **Thực hiện:** Tạo BRD từ spec, xác thực đầy đủ, theo dõi phê duyệt.
- **Không thực hiện:** Viết yêu cầu, thay thế công cụ quản lý sản phẩm.

## Điểm vào CLI

```bash
vds-cli brd --help
vds-cli brd --help
```

## Các Lệnh Chính

| Lệnh | Mục đích |
|---------|---------|
| `generate` | Tạo BRD |
| `validate` | Xác thực đầy đủ |
| `track` | Theo dõi phê duyệt |
