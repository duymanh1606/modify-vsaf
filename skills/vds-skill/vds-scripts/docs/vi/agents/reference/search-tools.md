# Search Tools

Preferred search stack for the WHO workspace:

- `rg` for fast text and file discovery
- `sg` for structural search
- `grepai` for semantic discovery when lexical search is insufficient
- `code-review-graph` for structural graph analysis after the target local Git repo is already known and caller/callee/import/blast-radius context is the real need
