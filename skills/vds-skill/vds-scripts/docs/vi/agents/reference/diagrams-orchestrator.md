# Điều Phối Viên Sơ Đồ

> Tạo sơ đồ C4, sequence, component, use case, và mermaid.

## Phạm vi

- **Thực hiện:** Tạo sơ đồ C4, sequence, component, use case, render mermaid.
- **Không thực hiện:** Tạo sơ đồ nghệ thuật, thay thế PlantUML server.
- **Người dùng chính:** AI agent (tài liệu kiến trúc), lập trình viên.

## Điểm vào CLI

```bash
vds-cli diagrams --help
vds-cli diagrams --help
```

## Các Lệnh Chính

| Lệnh | Mục đích |
|---------|---------|
| `c4` | Tạo sơ đồ C4 |
| `sequence` | Tạo sơ đồ sequence |
| `component` | Tạo sơ đồ component |
| `mermaid` | Render mermaid |
