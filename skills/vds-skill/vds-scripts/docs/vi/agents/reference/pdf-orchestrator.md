# Điều Phối Viên PDF

> Tạo PDF từ markdown và các định dạng khác.

## Phạm vi

- **Thực hiện:** Chuyển đổi markdown sang PDF, áp dụng templates, batch generate.
- **Không thực hiện:** Chỉnh sửa PDF hiện có, OCR.
- **Người dùng chính:** AI agent (giao tài liệu), operator.

## Điểm vào CLI

```bash
vds-cli pdf --help
vds-cli pdf --help
```

## Các Lệnh Chính

| Lệnh | Mục đích |
|---------|---------|
| `vds-cli pdf md2pdf` | Markdown sang PDF |
| `template` | Áp dụng template |
| `batch` | Batch generate |
