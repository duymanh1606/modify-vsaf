# Tổng quan Tính năng

Tổng quan 9 tính năng chính của VDS Ecosystem.

| Tính năng | Mô tả | Lệnh chính |
|-----------|-------|------------|
| CLI Audit | Kiểm toán repository | `vds-cli audit` |
| Worktree | Git worktree qua CLI | `vds-cli worktree` |
| Docs | Quản lý tài liệu | `vds-cli docs` |
| Skills | Đồng bộ skill | `vds-cli skills` |
| Progress | Báo cáo tiến độ | `vds-cli progress` |
| Scheduler | Lịch trình cron | `vds-cli schedule` |
| Confluence | Đồng bộ Confluence | `vds-cli confluence` |
| Bitbucket | Tìm kiếm Bitbucket | `vds-cli bitbucket` |
| Report | Báo cáo hàng ngày | `vds-cli report` |
